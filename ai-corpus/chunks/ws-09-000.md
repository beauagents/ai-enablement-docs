## Scope

Specify the rules for mediated tool access and compare open tool protocols.

## Key questions

1. Which open protocols exist, and what do they require of hosts, clients and servers?
2. How are tool profiles (scopes, rates, endpoints) expressed?
3. How is untrusted tool output handled?
4. How is user consent represented?
5. How are tool servers admitted, versioned and retired?

## Option families to compare

[RECOMMENDATION: compare all credible options. Do not select.]

- Open tool protocol
- Plain API gateway
- Brokered command interface
- Hybrid
