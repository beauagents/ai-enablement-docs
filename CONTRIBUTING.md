# Contributing

## Commit unit

One commit or pull request advances one workstream (WS01 to WS22). Use the structure in `vault/12-Meta-Templates/Template-Workstream-Commit.md`.

Suggested commit subject: `WSnn: <what was added>`.

## Before opening a change

1. Every new FACT has a wikilink to a parsed source record, and the record has an archive manifest.
2. New sources are added to `sources/Source-Registry.md`.
3. Options are listed with advantages, drawbacks and failure modes. No option is selected.
4. Decisions needed from the Human or the governance chain are added to `registers/Open-Questions.md`, not made.
5. Provider names appear only inside source records.
6. Vault notes and AI chunks are updated together. Chunk hashes match their parent sections.
7. Wikilinks resolve, and note file names stay unique.

## Supersession

Do not edit approved material in place. Add a new version that names what it supersedes. Keep the old one.

## Language

Direct and respectful. No flattery, no apologies as filler, no personal or diagnostic labels about people.
