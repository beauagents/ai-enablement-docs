# Template: Workstream Commit

Structural template for the commit and pull request that completes part of a workstream.

```markdown
Workstream: WSnn
Scope of this commit:
New or updated source records:
New or updated archive manifests:
Notes changed:
AI chunks regenerated: yes | no
Options added (with advantages, drawbacks, failure modes):
Decisions needed from the Human or governance chain (listed, not made):
Claims labelled UNVERIFIED that remain:
Provider names introduced outside source records: none
```
