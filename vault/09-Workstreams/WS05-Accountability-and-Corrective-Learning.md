# WS05: Accountability and Corrective Learning

**Status:** scaffold. Research not started. Work arrives as separate commits (see [[Template-Workstream-Commit]]).

## Scope

Define accountability records, incident reporting, and the loop that turns mistakes into tested changes.

## Key questions

1. What elements do incident and accountability records need?
2. How are delegation chains attributed so accountability is not diluted?
3. How are corrective changes validated against the failure case?
4. How are lessons promoted into rules through supersession?
5. When, if ever, does communication policy call for an apology?
